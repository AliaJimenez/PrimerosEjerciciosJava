# Primeros Ejercicios en Java ☕

¡Bienvenido/a a mi repositorio de prácticas iniciales en Java! Este espacio reúne un conjunto de pequeños proyectos desarrollados de manera independiente para dominar los fundamentos de la programación orientada a objetos, las estructuras de control lógicas y el manejo básico de datos en el lenguaje.

Todos los proyectos fueron estructurados utilizando el IDE **NetBeans** y se compilan mediante **Ant** (`build.xml`).

---

## 📁 Estructura del Repositorio

El repositorio está dividido en carpetas independientes, donde cada una representa un ejercicio práctico resuelto:

*   **`HelloWorld`**: El clásico programa inicial para verificar la correcta configuración del entorno de desarrollo.
*   **`datospersonales`**: Ejercicio enfocado en la declaración de variables, asignación de tipos de datos y salida estándar por consola.
*   **`mayorymenor`**: Uso de condicionales lógicos (`if-else`) para evaluar y comparar valores numéricos introducidos.
*   **`numerosimparesfor`**: Implementación del bucle `for` para iterar, filtrar y mostrar secuencias de números impares.
*   **`numerospareswhile`**: Uso de la estructura de control de flujo `while` para la generación controlada de números pares.
*   **`operacionesmatematicas`**: Práctica de operadores aritméticos fundamentales (suma, resta, multiplicación, división y módulo).
*   **`paroimpar`**: Algoritmo clásico que utiliza el operador de residuo (`%`) junto a condicionales para determinar la paridad de un número.
*   **`sumadenumerosdowhile`**: Uso práctico del bucle garantizado `do-while` para acumular sumas basándose en criterios de parada.
*   **`tablasdemultiplicar`**: Ejercicio de bucles para renderizar de forma ordenada tablas de multiplicación en la consola.

---

## 🛠️ Tecnologías y Herramientas Utilizadas

*   **Lenguaje:** Java SE (Standard Edition)
*   **IDE:** NetBeans
*   **Gestor de Construcción:** Apache Ant (incluye archivos de configuración `nbproject` y `build.xml` por proyecto)
